FORGE 115 — how to run on Windows
=================================

Easiest: double-click Forge115Setup.exe
--------------------------------------
1. Download Forge115Setup.exe (same GitHub folder as this file).
2. Double-click it. Allow Windows SmartScreen if it warns (More info -> Run anyway).
3. Click OK on the message.
4. Open Plutonium -> Black Ops II -> Zombies.
5. Start a PRIVATE match as HOST.
6. You should see: FORGE 115 loaded
7. Press N (Action Slot 1) to open the menu.

The EXE only copies scripts into:
  %localappdata%\Plutonium\storage\t6
It does not inject into Steam and does not bypass VAC.

You need
--------
- Call of Duty: Black Ops II on Steam
- Plutonium (free) — https://plutonium.pw/
  Open it once (Zombies) before running the EXE so folders exist.

Manual copy (if you don't want the EXE)
---------------------------------------
1. File Explorer address bar:

   %localappdata%\Plutonium\storage\t6\scripts\zm\forge115

2. Copy from the GitHub folder:

   public\gsc\scripts\zm\forge115\_menu.gsc
   public\gsc\scripts\zm\forge115\_actions.gsc
   public\gsc\scripts\zm\forge115\_config.gsc
   public\gsc\scripts\zm\forge115\_hooks.gsc
   public\gsc\maps\mp\gametypes_zm\_clientids.gsc

In the menu
-----------
Up / Down = move
Jump / Action Slot 4 = select
Melee = back / close

If you see nothing
------------------
- You were not host.
- Files are in the wrong folder.
- You joined public / official Steam. Use a private lobby.

You do NOT need VS Code, Node, or npm.
