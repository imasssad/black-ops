# FORGE 115

Zombies command overlay for **Call of Duty: Black Ops II** (private / hosted matches).

**Windows: double-click [Forge115Setup.exe](Forge115Setup.exe).**  
It copies the scripts into Plutonium. No Node, no npm, no VS Code.

This pack is **not** a Steam VAC injector. Official servers will not load it.

---

## How to run

1. Install [Plutonium](https://plutonium.pw/) and open Black Ops II → Zombies once, then quit.
2. Double-click `Forge115Setup.exe`. Click OK.
3. Plutonium → Zombies → **private match as host**.
4. You should see `FORGE 115 loaded`. Press **N** (Action Slot 1) for the menu.

Full steps: [HOW_TO_RUN.txt](HOW_TO_RUN.txt)
